# English & Urdu Learning App

A modern, interactive language learning application designed to help users learn **English** and **Urdu** through structured lessons, vocabulary practice, grammar explanations, pronunciation guidance, quizzes, and real-life conversations.

Whether you're an Urdu speaker learning English or an English speaker learning Urdu, this app provides an engaging and easy-to-follow learning experience.

---

## ✨ Features

* 🌐 Learn both English and Urdu
* 📚 Vocabulary with meanings and example sentences
* 📝 Grammar lessons with simple explanations
* 🎙 Pronunciation guidance
* 💬 Daily conversation practice
* 🧠 Interactive quizzes
* 🔄 English ↔ Urdu translation practice
* 📈 Track learning progress
* 🔍 Search words and phrases instantly
* 🌙 Light & Dark mode support
* 📱 Responsive design for mobile, tablet, and desktop
